# Donovan Fortune – CS Student Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript (no frameworks).

**Live site:** https://donvi143.github.io/portfolio-website/

## How to run it

- **Online:** open the live site link above.
- **Locally:** download or clone this repository and double-click `index.html` to open it in any browser. No install or build step is needed.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure using semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`) |
| `style.css` | Light/dark color variables, Flexbox and Grid layout, responsive media query |
| `script.js` | Greeting, footer year, mobile menu, dark mode, project filter, contact form validation |
| `images/` | Profile photo and project preview images |

## Features

- Semantic, commented HTML with alt text, a skip link, and ARIA labels for accessibility
- SEO meta description and page title
- Light and dark themes built with CSS custom properties
- Responsive layout: Flexbox header/hero, CSS Grid for skills and projects, mobile menu under 700px
- Project filter buttons (All / Web / Python)
- Contact form with live validation, error messages, character counter, and success message
